Setting it up

Full guide for the production team: Broadcasting (ON AIR) — setup steps, caveats, and what to check when a graphic goes stale. That page needs no login, so it can be sent to anyone.

vMix: Add Input → Data Sources → XML, paste the address, set the refresh interval to 1–2 seconds. Then map each column onto a field in your title.
Anything else: the feed is a plain web address returning XML or JSON, so any software that can poll a URL will read it. Switch the format above to whichever your package prefers.

One row per record. The scoreboard, drive and last-play feeds return a single row. The leader feeds return one row per player, best first — so a “top rusher” graphic can simply use row 1.

Screen overlay

A ready-made transparent scoreboard, if you would rather not build your own. Add it as a web browser input at 1920×1080 — the background is transparent, so it keys straight over the programme feed.

If the graphics stop updating

Open one of the addresses in a browser. If it shows current data, the feed is fine and the problem is in the broadcast software — check the refresh interval is set, since a data source that never refreshes looks exactly like a frozen feed.

If it says No game is on air, nobody has set a game ON AIR on the dashboard yet.
