Roster file format

A spreadsheet (.xlsx or .xls) with three columns, in this order. A header row is fine — it will be ignored.

ABC
1#NamePosition
27Alpha AtesRB
312Bravo BooneQB
421Charlie Cole

Row 1 is optional — a header row is ignored. Row 4 shows a player with no position, which is fine.

A — NumberB — NameC — Position
7Alpha AtesRB
12Bravo BooneQB

Position is optional. Leave column C blank for anyone you do not have a position for — a roster with positions for the starters only imports fine. List more than one if you like — only the first is used. RB/WR, RB, WR and RB-WR all read as RB. Put the position they mostly play first. Two players may share a number; you will be asked which is which.

Offense: QB RB FB HB TB WR SE FL SLOT TE OL OT OG G T C ATHLETE
Defense: DB CB S FS SS LB OLB ILB MLB WLB DE DT NG NT EDGE DL
Special teams: K P LS DS H KR PR RET ST

Clear this season's roster

Removes every player from the currently selected season. Uploading normally MERGES into what is already here, which is right during a season and wrong when you want a clean start — use this to wipe a wrong upload and try again.

Other seasons are never affected by this, or by anything else on this page — each season's roster is its own, separate list. Every finished game also keeps its own roster snapshot, taken when the game was created, and all stats are calculated from the plays themselves. Old recaps, stat packages and season reports read exactly the same afterwards.

Type CLEAR to confirm.
